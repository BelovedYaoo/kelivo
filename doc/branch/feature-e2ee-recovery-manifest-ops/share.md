# 恢复成员清单操作协作摘要

- 分支：`feature/e2ee-recovery-manifest-ops`，基线 `feature/e2ee-chat-runtime@b8c1b7bd`。
- 目标：为 KELIVOMM v1 增加操作 4 `recoverResume` 与操作 5 `recoverReplace` 的 Dart wire 构建、解析、验签和历史推进。
- 边界：不接 UI、Provider、API，不修改 Rust；与 `feature/e2ee-recovery-media` 共享固定 manifest bytes/digest 校验跨语言 wire。
- 当前：已确认 #49 覆盖恢复闭环、#51 覆盖 ARK 轮换，不新建重复 Issue；正在核对既有 builder/verifier/history 不变量。

## Mini Control Contract

- Primary Setpoint：KELIVOMM v1 增加 op4 `recoverResume` 与 op5 `recoverReplace`，只提供可验证的 Dart wire builder/verifier/history 语义。
- Acceptance：既有测试覆盖正常、字段或签名篡改、重复 operationId、多次顺序 resume、resume 后 replace、ready 直达 replace，并由 Rust parser 消费一组 Dart builder 固定 bytes/digest。
- Guardrails：旧 op1-3 不退化；服务器 nonce 与 phase 不进入签名 payload；不接 UI、Provider、API；不修改 Rust。
- Boundary：成员清单模块、锚点后继约束、既有协议与数据库测试、此协作文件。
- Risks：恢复双 ARK 验签边界、全历史 operationId 唯一性、Dart/Rust 字段偏移或签名 transcript 漂移。
