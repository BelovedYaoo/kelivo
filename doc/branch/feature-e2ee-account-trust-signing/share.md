# 协作记录

- 目标：从指定 ARK 代次派生账户信任根 Ed25519 签名能力，为签名设备成员清单提供安全核心原语。
- 基线：`b82b1834`；沿用 Issue #51，不实现成员清单、撤销事务或服务端逻辑。
- 派生：HKDF-SHA256 以 ARK 为 IKM，info 固定绑定协议域、规范 userId 与大端 keyEpoch，输出 32 字节 Ed25519 seed。
- 签名：固定协议域绑定 userId、keyEpoch、payload 长度与 1 至 65536 字节规范 payload；使用严格 Ed25519 验证。
- 边界：ABI v11 只暴露 32 字节本地派生验证钥与 64 字节签名；原始 ARK 和 seed 不跨 ABI，服务器裸公钥不建立信任。
- 账户绑定：ARK 注册表原子保存规范 userId 与密钥环；生成、恢复、信封、配对、附件、签名及合并路径均拒绝跨账户使用，Dart 句柄公开不可变 userId。
- 验证：协议 41 项、原生 48 项、依赖 Flutter 19 项测试通过；依赖与根 `lib/test` 分析通过，根账户、配对及状态恢复五个定向场景通过。
