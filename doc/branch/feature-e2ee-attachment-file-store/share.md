# E2EE 附件原子文件存储

- 范围：仅实现附件自有文件的原子发布、完整性读取和受限删除。
- 接口：生产文件系统 adapter 与内存 adapter 共享同一 seam。
- 路径：生产文件只能位于账号工作区 `upload/e2ee`，固定布局禁止调用方拼接相对路径。
- 不涉及：数据库/schema、同步 runtime、payload、聊天适配器。
- 完成：生产 adapter 使用同目录独占临时文件、文件 flush、完整文件屏障、无覆盖重命名与目录屏障完成原子发布。
- 完成：读回以持久 descriptor 的精确长度和 SHA-256 为权威；冲突、篡改、越界、异常实体和非字节源均失败关闭。
- 完成：下载 staging 与上传 staging 隔离，最终内容固定为 `upload/e2ee/content/<contentSha256>`；仅 staging 允许删除。
- 完成：内存 adapter 复用同一接口，现有同步协议测试文件新增成功、边界、错误和状态转换场景。
- 验证：目标文件静态分析无问题，附件文件 adapter 定向测试 2/2 通过。
- 已知基线：完整同步协议测试 95 项中仅旧 payload 版本断言失败（实际 v2、期望 v1），不属于本分支范围，已通知主线。
